This project aims to create a single, idempotent webserver installation script in Bash. Its goal is to fully support a Laravel-based web app.

The stack consists of the following...
- Caddy: Webserver
- Crowdsec: Generic server security, check both HTTP, SSH and potentially other traffic.

For the finished script, follow the Google Shell Style Guide: https://google.github.io/styleguide/shellguide.html
